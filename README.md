# BalkanPuppyHub

Business website for a Bernese Mountain Dog breeding and import operation based in Novi Sad, Serbia.

## About
BalkanPuppyHub specializes in breeding and importing premium Bernese Mountain Dogs from Serbia to the United States. All puppies are health tested, vaccinated, and come with full documentation.

## Features 
-Dog gallery with lightbox image viewer
-Contact form for inquiries
-Parents section showcasing breeding dogs
-Google Analytics integration for traffic tracking

## Tech Stack
-HTML5
-CSS3
-JavaScript
-Google Analytics
-Hosted via GitHub Pages
